# Performance investigations

This folder holds profiling methods, performance roadmaps, dated measurements, and resumable
cross-title performance handoffs. Describe the frontend, source cohort, route, counters and limits
behind a conclusion; retain falsified hypotheses and missing observations. Game trackers and
title status documents hold the live rendering frontier. Scheduling and lane ownership belong in
`prosper/docs/process/GAME_COMPAT_ORCHESTRATION.md`; raw machine-local evidence stays outside Git.

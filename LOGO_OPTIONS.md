# Prosper logo options

Both options are icon-first, roughly circular, and designed to stay inside common rounded-square and
circular app-launcher masks. The source assets are 1254×1254 transparent PNGs with no baked-in
background, so they work on GitHub's light and dark themes.

![Prosper logo options on light and dark backgrounds](assets/logo-options/prosper-logo-options-preview.png)

## Option A — Portal P

<p align="center">
  <img src="assets/logo-options/prosper-portal-p.png" alt="Option A: Portal P" width="320">
</p>

A broken circular ring forms a lowercase `p`, with a small crossing element representing translation
between systems. This option is more letter-like and directly tied to the Prosper name.

## Option B — Bridge Loop

<p align="center">
  <img src="assets/logo-options/prosper-bridge-loop.png" alt="Option B: Bridge Loop" width="320">
</p>

Two rounded bands form a continuous loop with a forward arrow. This option is more compact and reads
more clearly as a launcher icon at small sizes.

## Selection

Choose **Option A** or **Option B** in the pull request discussion. The current README logo is left
unchanged in this comparison PR; the selected icon can replace it after review.
